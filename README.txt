Inkwell Supply - installable PWA (prototype, data in localStorage)

Run locally:   python3 -m http.server 8080   then open http://localhost:8080
Host online:   upload all files to any static HTTPS host (Netlify, Vercel, GitHub Pages, Cloudflare Pages).
Install:       Android Chrome -> menu -> Install app. iPhone Safari -> Share -> Add to Home Screen.
Admin portal:  open the app URL with #admin at the end, or tap Admin on the Home screen.
After editing index.html, bump V in sw.js (e.g. inkwell-v2) so phones pick up the update.
